Asignación de roles

Los permisos se asignan por empleado. Abre la ficha de un empleado y usa «Rol y estado» para asignar o retirar el rol de administrador, además de activar o desactivar la cuenta.

Nota: el sistema define dos roles de negocio fijos (Empleado y Administrador) sobre el campo rol de cada usuario. No se pueden crear roles adicionales desde la interfaz: la asignación y retirada de permisos se realiza por empleado y solo un administrador puede modificar el rol de otro usuario (nunca el propio).
